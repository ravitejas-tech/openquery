# v0.1 Build Plan

The scope for the first release. For _how_ the system is put together and why, see
[architecture.md](../architecture.md).

**Goal of v0.1:** make the README true. Everything it advertises should work, and the
contributor workflow should be good enough that a first-time PR can land without a
conversation.

---

## Decisions

Settled before implementation, so they are not re-litigated mid-build:

| Decision    | Choice                      | Rationale                                                   |
| ----------- | --------------------------- | ----------------------------------------------------------- |
| HTTP client | User-supplied client module | Zero runtime deps; auth/interceptors stay in user code      |
| Query keys  | Path-segment array          | Enables prefix invalidation across a resource tree          |
| Pagination  | Opt-in, off by default      | OpenAPI has no pagination standard; guessing fails silently |
| Swagger 2.0 | Supported                   | Comes free with the Redocly loader                          |

### Dependencies

Deliberately few: `@redocly/openapi-core` (parse/bundle), `prettier` (format output),
`cac` (CLI), `chokidar` (watch), `jiti` (load TS config).

**No peer dependencies.** Generated code imports only `react-query-kit`,
`@tanstack/react-query`, and the user's client module.

Built with **tsdown** (the Rolldown-based successor to tsup, which is no longer
actively maintained) — dual ESM/CJS plus `.d.ts`.

## Verification

1. `npm install && npm run build` — builds dual ESM/CJS plus types
2. `npm test` — unit and snapshot suites pass
3. `npx tsc --noEmit` over generated Petstore output — **generated code compiles**
4. In `examples/petstore-react/`: `npx queryfish generate` reproduces committed output
   byte-for-byte; `npm run dev` renders live data
5. `npx queryfish generate --dry-run` on an unchanged spec reports no changes
6. The edge-case spec generates without hanging (circular-ref regression guard)

## Risks

| Risk                                  | Mitigation                                                                             |
| ------------------------------------- | -------------------------------------------------------------------------------------- |
| Circular `$ref` hangs the generator   | Cycle-safe walk plus a dedicated fixture — designed in, not discovered at runtime      |
| Client interface ends up axios-shaped | Minimal structural `Client` interface; a `fetch` adapter is verified in the test suite |
| Snapshot churn swamps PRs             | Snapshots _are_ the review surface; `CONTRIBUTING.md` explains how to read them        |

## Beyond v0.1

Deferred deliberately, and cheap to add because each is a new emitter over the
existing IR:

- Zod schema generation for runtime validation
- MSW mock handler generation
- Plugin system for custom output
- React Query Suspense variants (`createSuspenseQuery`)
